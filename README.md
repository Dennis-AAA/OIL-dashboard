# 全球原油与成品油供求看板

一个单文件数据看板网页,追踪全球原油与成品油市场供求关系,每周五自动更新(Asia/Shanghai)。

## 内容

- **美国(EIA 周度)**:商业原油库存、SPR、汽油库存、馏分油库存、库欣库存、原油产量、炼厂开工率、原油/成品油出口、活跃原油钻机数
- **价格**:WTI 现货、3-2-1 裂解价差(按纽约港汽柴油现货计算)
- **中国(恒生聚源周度)**:商业原油库存指数、山东地炼与主营炼厂开工率、炼油毛利
- **OECD(季度)**:陆上商业石油库存

所有图表展示 2016 年以来的十年走势。

## 使用

直接打开 `index.html`,或通过 GitHub Pages 访问。数据仅供参考,不构成投资建议。

数据来源:美国能源信息署 (EIA) 周度石油状况报告、恒生聚源 (Gildata) 宏观行业库。
